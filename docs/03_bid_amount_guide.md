# 03. 사업규모금액 5분위별 유찰률 — 실행 가이드

## 1. 목적 및 기준

입찰공고의 기초금액(`bsicExpt`)을 직접 사용하지 않고, **조달계획 예산금액과 품목명세서 총액**으로 공식 사업규모금액을 산정한 후 **2021~2023년 학습기간 5분위 경계**를 고정하여 2024년과 비교한다. 각 기간별 기술통계, 유찰률, 카이제곱 독립성 검정, Cramér's V 및 데이터 품질 검증을 수행한다.

- 공식 코드: [`scripts/analysis/03_bid_amount_analysis.py`](../scripts/analysis/03_bid_amount_analysis.py)
- 출력: [`data/analysis/bid_amount/`](../data/analysis/bid_amount/)
- 분석 기간: 2021~2023년 학습, 2024년 별도 비교(공고일 `pblancDate` 기준). **2025년 제외**
- 분석 단위: `noticeKey` 기준 공고 1건; 동일 사업의 품목 여러 행은 `businessKey` 기준 합산 후 공고에 결합

## 2. 입력 파일과 필수 조건

`data/clean/`의 CLEAN CSV 4종:

| 파일 접두사 | 필수 주요 컬럼 | 사용 목적 |
|---|---|---|
| `bid_notice_clean_20210101_20251231` | `noticeKey`, `businessKey`, `pblancDate`, `pblancSe`, `cntrctMth` | 공고 단위 분석 모집단 |
| `bid_result_clean_20210101_20251231` | `noticeKey`, `bidResult`, `bidMth` | 유찰 여부 및 과거 입찰방법 사후 복원 |
| `procure_plan_clean_20210101_20251231` | `businessKey`, `bidMth`, `budgetAmount` | 총액제 예산 우선 적용 |
| `bid_item_clean_20210101_20251231` | `businessKey`, `totlAmnt` | 유효 사업별 품목총액 |

CSV는 `utf-8-sig`로, 주요 식별자는 문자열로 읽는다. `noticeKey`와 계획의 `businessKey` 중복/결측은 오류로 중단한다. 결과는 공고키 단위로 상태를 합치고, 유찰+비유찰 혼합은 `판단보류`, 낙찰+순위확정 혼합은 낙찰로 처리한다.

**분석 대상:** 공고일이 2021~2024년이고 결과확정(유찰·낙찰·순위확정), 취소공고 아님, 계약방법 문자열에 `수의`가 포함되지 않는 공고. 유찰=1, 낙찰·순위확정=0. `분석 기간 전체`와 `사업규모금액 계산 가능 표본`을 구분한다.

## 3. 사업규모금액 산정 로직

1. **입찰방법 `bidMth`:** 조달계획의 총액제/단가제 우선; 계획에서 확인할 수 없으면 **과거 분석 전용**으로 입찰결과의 단일 `bidMth`를 이용해 복원(`입찰결과_사후복원`). 이 사후 복원을 신규 공고의 위험도 입력이나 2025년 평가에서 자동 적용하면 타깃 시점 누수 가능성이 있다.
2. **품목 총액 유효성:** 사업키에 속한 모든 품목 `totlAmnt`가 숫자·0 이상이고 합계가 **0 초과**일 때만 유효하다. 일부 품목 금액이 결측/음수이면 해당 사업 품목합계는 사용하지 않는다.
3. **총액제:** 양수인 조달계획 예산 우선, 예산이 없으면 유효한 품목합계 대체.
4. **단가제:** 조달계획 예산은 총액으로 사용하지 않고 유효한 사업별 품목합계만 사용.
5. **총액제 품질 보류:** 예산과 품목합계가 모두 존재하면 `abs(예산−품목합계)/예산` 계산. **10% 초과면** 금액을 NA로 변경, 10% 이하는 유지.
6. **금액 미확인:** 사업규모금액 분석의 5분위 유찰률·검정에서는 제외. KPI 평가에서는 공식 KPI 코드가 정한 상위 변수조합으로 대체하는 별도 로직을 사용한다.

**주의:** `비율 10%`은 유찰률이 아니라 **총액제의 예산 대비 품목총액 불일치율**이다. 품목총액은 시장가격의 적정성 검정 결과가 아니다.

2021~2023년 전체 경쟁성 공고 유찰은 **3,426건**이나 사업규모금액 분석 금액 유효 표본에서는 **3,420건**이다. 2024년 전체 유찰은 **1,506건**, 금액 유효 표본은 **1,504건**이다. 원인은 사업규모금액 분석 금액 필터의 별도 표본 제한이며, 수치를 강제로 동일하게 맞추지 않는다.

2021~2023년에는 Q1→Q5 유찰률이 대체로 하락하지만, 2024년에는 동일한 순서가 일관되게 나타나지 않는다. 단일 금액 변수의 인과적 영향·예측 성능으로 단정하지 않는다.

## 8. 카이제곱 독립성 검정

자료: [`04_카이제곱_CramersV.csv`](../data/analysis/bid_amount/04_카이제곱_CramersV.csv).

| 지표 | 2021~2023년 | 2024년 |
|---|---:|---:|
| 검정 공고 수 | 21,064 | 6,775 |
| χ² | 186.0818 | 50.3263 |
| 자유도 | 4 | 4 |
| p값 | 3.68×10⁻³⁹ | 3.09×10⁻¹⁰ |
| Cramér's V | 0.0940 | 0.0862 |
| 최소 기대빈도 | 683.71 | 218.00 |
| 기대빈도 5 미만 셀 | 0 | 0 |
| 결과 (유의수준 0.05) | 유의 | 유의 |

각 기간별 5×2 교차표(금액 5분위 × 유찰/비유찰)에 `chi2_contingency(...,correction=False)`를 적용한다. 귀무가설은 금액 5분위와 유찰 여부가 독립이라는 것이며, **두 기간 모두 기각**된다. 다만 V가 0.1 미만으로 **관련 강도는 작다**. 본 사업규모금액 분석 검정에는 코드상 Holm 보정이 없으며, 공식 KPI의 4변수 조합 검정이나 상위 20% 사전 식별률과 구분한다.
